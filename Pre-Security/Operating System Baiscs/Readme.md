### Linux vs. Windows — Command Equivalents
 
| Task | Linux | Windows |
|---|---|---|
| Show current directory | `pwd` | `cd` (no args) |
| List directory contents | `ls` | `dir` |
| List hidden items | `ls -al` | `dir /a` |
| Change directory | `cd <path>` | `cd <path>` |
| Move up one level | `cd ..` | `cd ..` |
| Search for a file | `find <path> -name <file>` | `dir /s <file>` |
| Read a file | `cat <file>` | `type <file>` |
| Show current user | `whoami` | `whoami` |
| Show hostname | `hostname` | `hostname` |
| Show system/OS info | `uname -a` | `systeminfo` |
| Show network config | `ip a` / `ifconfig` | `ipconfig` |
| Show disk usage | `df -h` | `systeminfo` (partial) |
